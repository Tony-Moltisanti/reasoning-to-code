# Course Roadmap

## Reasoning to Code

**A progressive learning journey from logical reasoning to programming
and software quality engineering.**

## Purpose of This Roadmap

This roadmap describes the eight milestones in the Reasoning to Code
learning journey. It provides an overview of what each milestone covers
and the capabilities I am working towards.

The course starts with the fundamentals and progresses towards practical
programming and professional software testing. Each milestone builds on
the understanding developed in the previous milestones.

A milestone is considered complete when I can demonstrate that I
understand and can apply its key concepts. Completing lessons alone is
not enough.

------------------------------------------------------------------------

## Milestone 1: Understanding Logic

### Focus

Learn what logic is and how information, rules, reasons, and conclusions
relate to one another.

### Topics

-   What logic means.
-   Statements and information.
-   Facts and assumptions.
-   Rules and conditions.
-   Reasons and conclusions.
-   Using information to reach a conclusion.

### Expected ability

Explain a simple situation, identify the relevant information and rule,
and determine what conclusion follows.

------------------------------------------------------------------------

## Milestone 2: Building Reasoning Ability

### Focus

Develop the ability to examine arguments and decide whether conclusions
follow from the reasons given.

### Topics

-   Premises and conclusions.
-   Valid and invalid reasoning.
-   Consistency and contradictions.
-   Common reasoning errors and fallacies.
-   Explaining why a conclusion is or is not supported.

### Expected ability

Evaluate simple arguments, identify weak reasoning, and explain the
difference between a supported conclusion and an unsupported assumption.

------------------------------------------------------------------------

## Milestone 3: Conditional Logic

### Focus

Understand how conditions determine whether something should happen.

### Topics

-   If/then reasoning.
-   AND, OR, and NOT.
-   Necessary and sufficient conditions.
-   Combining conditions.
-   Truth tables.
-   Understanding how changing a condition changes an outcome.

### Expected ability

Read a set of conditions, work out the possible outcomes, and explain
when a rule should or should not be satisfied.

------------------------------------------------------------------------

## Milestone 4: Analytical Problem-Solving

### Focus

Learn to break problems down, examine possibilities, and reason through
different outcomes systematically.

### Topics

-   Decomposing a problem into smaller parts.
-   Identifying constraints and possibilities.
-   Decision tables and decision trees.
-   Recognising patterns.
-   Considering boundary conditions.
-   Comparing possible solutions.

### Expected ability

Approach an unfamiliar problem methodically, organise the relevant
possibilities, and explain a solution before attempting to implement it.

------------------------------------------------------------------------

## Milestone 5: Computational Thinking

### Focus

Learn how to express a solution in a form that a computer can follow.

### Topics

-   Computational thinking.
-   Decomposition, pattern recognition, and abstraction.
-   Algorithms and step-by-step instructions.
-   Pseudocode.
-   Variables and data.
-   Decisions and loops.
-   Functions and state.
-   Tracing an algorithm.

### Expected ability

Turn a clearly understood problem into an ordered algorithm or
pseudocode and trace how it behaves.

------------------------------------------------------------------------

## Milestone 6: Programming Logic

### Focus

Translate logical reasoning and algorithms into working program code.

### Topics

-   Translating pseudocode into code.
-   Programming conditions.
-   Loops and functions.
-   Working with data.
-   Understanding application behaviour and state.
-   Applying programming logic with PHP.
-   Connecting programming concepts to Laravel examples.

### Expected ability

Write and explain small programming solutions, showing how the code
implements the rules and reasoning behind the solution.

------------------------------------------------------------------------

## Milestone 7: Software Testing

### Focus

Learn to check whether software behaves correctly and discover
situations in which it may fail.

### Topics

-   Requirements and business rules.
-   Turning rules into test cases.
-   Positive and negative testing.
-   Edge cases.
-   Boundary-value testing.
-   Expected and actual results.
-   Test design and test documentation.
-   Identifying defects and describing them clearly.

### Expected ability

Design useful test cases for a feature, including normal, invalid,
unusual, and boundary situations, and explain what each test is intended
to verify.

------------------------------------------------------------------------

## Milestone 8: Advanced Testing Engineering

### Focus

Develop practical skills for testing real applications and building
reliable automated tests.

### Topics

-   Test-driven development (TDD).
-   PHPUnit.
-   Laravel testing.
-   Unit, feature, and integration testing.
-   Testing interactions between application components.
-   Data consistency and concurrency risks.
-   Security-related testing considerations.
-   Performance considerations.
-   Test automation and maintainable test suites.

### Expected ability

Plan and implement appropriate automated tests for application
behaviour, interpret the results, and use testing to improve software
reliability.

------------------------------------------------------------------------

## Practical Learning Examples

The course will use progressively more realistic examples.

### Bookshop examples

Bookshop situations will help introduce rules, quantities, decisions,
and simple problem-solving without requiring programming knowledge at
the beginning.

### Clinic appointment-booking examples

Clinic booking situations will help apply reasoning to realistic
business rules, such as appointment availability, booking restrictions,
and appointment status.

### PHP and Laravel applications

As programming knowledge develops, the same reasoning will be translated
into PHP and Laravel code and tested systematically.

Any real project examples shared publicly must be sanitised. Do not
commit patient information, passwords, API keys, credentials, or other
private data to this repository.

------------------------------------------------------------------------

## How Progress Is Measured

Progress is based on demonstrated understanding and practical
application.

For each milestone, I will aim to:

1.  Understand the concepts and explain them in my own words.
2.  Complete the exercises and explain my reasoning.
3.  Apply the concepts to practical examples.
4.  Review mistakes and correct misunderstandings.
5.  Complete the milestone assessment.
6.  Record the outcome and important lessons in the repository.

At the completion of each milestone, a comprehensive PDF summary will be
prepared containing the milestone's lessons, explanations, examples,
exercises, worked solutions, practical connections, assessment, and next
steps.

## Guiding Principle

**Reason first. Build second. Test thoroughly.**

The aim of this journey is to develop the habit of understanding a
problem, reasoning through its rules and possible outcomes, translating
a sound solution into code, and testing that solution carefully.
