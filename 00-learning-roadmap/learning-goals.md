# Learning Goals

## Overall Goal

To develop strong logical reasoning, computational thinking, programming
problem-solving, and software testing skills.

I want to become someone who can understand a problem, reason through
possible solutions, translate a sound solution into code, and test that
code carefully.

## 1. Logical Thinking

-   Understand what logic is and how reasoning works.
-   Distinguish facts, assumptions, rules, reasons, and conclusions.
-   Recognise valid and invalid reasoning.
-   Identify contradictions and common reasoning errors.
-   Explain why a conclusion follows from the available information.

## 2. Analytical Problem-Solving

-   Break complex problems into smaller, manageable parts.
-   Identify constraints, conditions, and possible outcomes.
-   Compare possible solutions systematically.
-   Recognise patterns and important boundary conditions.
-   Explain a solution step by step before attempting to code it.

## 3. Computational Thinking

-   Understand decomposition, pattern recognition, abstraction, and
    algorithms.
-   Describe solutions using clear, ordered steps.
-   Read and write simple pseudocode.
-   Understand variables, decisions, loops, functions, and state.
-   Trace an algorithm to understand how its state changes.

## 4. Programming Logic

-   Translate a reasoned solution into working code.
-   Understand conditions, loops, functions, and data structures.
-   Practise programming logic with PHP.
-   Apply the concepts to Laravel application behaviour and business
    rules.
-   Read code and explain what it does and why it works.

## 5. Software Testing

-   Understand the purpose of software testing.
-   Turn business rules and requirements into test cases.
-   Design positive, negative, and boundary tests.
-   Identify edge cases and unexpected inputs.
-   Check that software handles invalid situations safely and
    predictably.
-   Explain why each test is necessary and what it proves.

## 6. Advanced Testing Engineering

-   Learn test-driven development (TDD).
-   Practise automated testing with PHPUnit.
-   Test Laravel applications, including feature and integration
    behaviour.
-   Understand risks involving data consistency, concurrency, and
    security.
-   Build maintainable and useful automated test suites.

## How I Will Learn

-   Start with fundamentals and assume no prior knowledge where
    necessary.
-   Progress from simple examples to more complex problems.
-   Practise before moving to the next concept.
-   Explain my reasoning, not just the final answer.
-   Apply concepts to realistic bookshop and clinic-booking examples.
-   Keep useful notes, exercises, solutions, and project evidence in
    this repository.
-   Review my understanding at the end of each milestone.

## What Success Looks Like

I will be making progress when I can:

1.  Understand a problem and identify the information and rules that
    matter.
2.  Explain a logical solution clearly.
3.  Convert that solution into an algorithm and then code.
4.  Predict how the code should behave in different situations.
5.  Design tests that check normal behaviour, invalid behaviour, and
    edge cases.
6.  Explain what a test result tells me and what it does not tell me.

This is a progressive learning journey. I will update these goals and
record evidence of my progress as my skills develop.
